# Audio Feature Lab

## Abstract

This project is a playable laboratory for Unity's built-in audio system. It shows how sounds are played and shaped with `AudioSource` (including 2D and 3D spatialization), how hearing is placed with `AudioListener` independently of the camera, how audio enters and leaves the engine (microphone input and the active output configuration), and how buses are arranged with the Audio Mixer, groups, and snapshots. A C# library supplies reusable pieces for equal-power source crossfades, snapshot crossfades, microphone peak levels, definable FFT bands, DSP-scheduled stems, occlusion filtering, Doppler motion, and a musical clock. Example scenes wire those scripts to the keyboard so each idea can be heard immediately.

## Software

| Item | Version / choice |
| --- | --- |
| Unity | 6000.4.1f1 (Unity 6.4). A later Unity 6 editor can open the project; allow the upgrade if Hub asks. |
| Render pipeline | Built-in. The project does not use URP or HDRP. |
| Audio | Unity's built-in audio engine and Audio Mixer. No FMOD Studio or Wwise project is included. |
| Input | Unity Input Manager (`UnityEngine.Input`). The Player setting **Active Input Handling** is Input Manager. |
| Clips | Synthesized WAV files in `Assets/AudioFeatureLab/Clips`, generated by `Tools/generate_clips.py`. They are original tones, not licensed recordings. |

## Script language

Scripts are C# for the Unity player. The project uses Unity's default API compatibility level (the .NET profile shipped with Unity 6, compatible with .NET Standard 2.1). Language features stay within what that profile compiles by default: classes, generics, and coroutines, without requiring a newer language version in the project settings.

Runtime scripts live in `Assets/AudioFeatureLab/Runtime` and compile into the `AudioFeatureLab` assembly, namespace `AudioFeatureLab`. Editor-only setup lives in `Assets/AudioFeatureLab/Editor`, namespace `AudioFeatureLab.EditorTools`.

## Open and play

1. Install Unity 6000.4.1f1 or a newer Unity 6 editor with Unity Hub.
2. **Add** this folder from disk: the folder that contains `Assets`, `Packages`, and `ProjectSettings`.
3. Open `Assets/AudioFeatureLab/Scenes/00_MainMenu.unity`.
4. Press Play. Click a scene button, or press 1–5.
5. Click the Game view before using keys, so the editor does not take them.

If the scenes are missing, use the menu **Audio Feature Lab > Build Demo Scenes** after the scripts have compiled. That rebuilds `DemoMixer` and the six scenes. It needs the WAV files in `Assets/AudioFeatureLab/Clips`.

## Library

Components are under **Component > Audio Feature Lab** as well as the namespace `AudioFeatureLab`.

| Script | Role |
| --- | --- |
| `AudioSourceCrossfader` | Equal-power or linear crossfade of two `AudioSource`s. Keys 1–9. Public `blend`, `sourceAGain`, `sourceBGain`. |
| `SnapshotCrossfader` | Crossfade of two `AudioMixerSnapshot`s via `TransitionToSnapshots`. Keys 1–9. Public `blend`, `weightA`, `weightB`. |
| `MicrophoneCapture` | Starts `Microphone.Start` and routes it to an `AudioSource` for monitoring. |
| `MicrophonePeakMeter` | Peak and RMS of the microphone. Public `peak`. |
| `FrequencyBandAnalyzer` | FFT with a list of ranges. Each `FrequencyBand.level` is a public float. |
| `ListenerSpectrumTap` | Copies the listener mix on the audio thread. Public output `peak`. Must sit on the `AudioListener`. |
| `OutputLevelMeter` | Peak and RMS from `AudioSource.GetOutputData`. |
| `ListenerPerspectiveRig` | Moves the listener with the camera or away from it. |
| `SpatialAudioController` | Writes spatial blend, Doppler, spread, rolloff, pan, and priority. |
| `DistanceRing` | Draws min and max distance. |
| `OcclusionLowPass` | Closes an `AudioLowPassFilter` when an AudioOcclusion collider blocks the listener. Public `occlusion`. |
| `DopplerShuttle` | Moves a 3D source so Doppler shift is obvious. |
| `SharedTransport` | One `AudioSettings.dspTime` start for every scheduled voice. |
| `SyncedStemPlayer` | `PlayScheduled` loops with per-stem gain and keyboard toggles. |
| `OneShotPool` | Overlapping one-shots in 2D or at a world position. |
| `MusicClock` | Beat, bar, and pulse from DSP time and BPM. |
| `AudioDevicePanel` | Lists input devices and the active output configuration. Can reset DSP buffer size and speaker mode. |
| `ExposedVolumeKeys` | Nudges exposed mixer parameters and clears snapshot overrides. |
| `MixerGroupOutput` | Assigns `AudioSource.outputAudioMixerGroup`. |
| `AudioFader` | Fades one source in or out. |
| `AudioPauseKey` | `AudioListener.pause` and `AudioListener.volume`. |
| `ReverbZoneReadout` | Reports whether the listener is inside an `AudioReverbZone`. |
| `AudioUnits`, `SimpleFft`, `SpectrumBands` | Decibels, equal-power gains, and the FFT used by the analyzer. |

`AudioLabMathTests` checks the FFT and gain math. The scene builder runs it before writing scenes.
